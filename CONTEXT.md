# Portfolio

Will Mann's personal site: projects, writing, and the copy that presents them.

## Language

**Content**:
The structured records and media the site displays — pages, projects, technologies, blog posts, their bodies, and their images.
_Avoid_: CMS documents

**Copy**:
The prose those records (and the Hero) display — wording, not the records themselves.
_Avoid_: Content (when meaning the wording)

**Positioning**:
Who the public site says Will is now: Senior Software Engineer at Runna (acquired by Strava), leading app infrastructure.
_Avoid_: Bio, personal brand, graduate narrative

**History**:
Pre-Runna work the site still shows. It is not Positioning.
_Avoid_: Recent work (for school, uni, or PwC-era projects)

**Side project**:
A personal or student build shown in Projects. Not employment, not Positioning.
_Avoid_: Case study of a job, recent work (for these cards)

**Journey**:
The short career path About may tell (school → Flying Start → PwC → Runna). Compressed; not CV bullets.
_Avoid_: Autobiography, second CV

**Local content**:
Content owned as files in this repository, which the site reads instead of a hosted CMS. Prose lives in Markdown with YAML frontmatter; technologies live in one YAML list; images live as files in the repo.
_Avoid_: Crawl dump, scraped pages, Sanity export (those are ways of obtaining it)

**Published content**:
The production records the public Sanity API already returns — what the live site shows. This move copies those; unpublished drafts are not in play unless the Sanity account is recovered.

**Upgrade**:
A later effort to change the site's stack, design, or features. Out of scope for moving content off Sanity.
_Avoid_: Redesign, rewrite (when meaning this content move)
